# 🌱 HumiTech — Agricultura Inteligente

A **HumiTech** é um projeto acadêmico desenvolvido com o objetivo de apresentar uma solução de **IoT aplicada ao agronegócio**, utilizando sensores para auxiliar no monitoramento das condições de uma plantação.

## 📌 Sobre o projeto

O projeto apresenta uma proposta de agricultura inteligente na qual sensores coletam informações do ambiente e permitem acompanhar condições importantes para o desenvolvimento das plantas.

A ideia principal era utilizar tecnologia para tornar o monitoramento agrícola mais eficiente, ajudando o produtor a tomar decisões com base em dados.

## ⚙️ Como funcionava

A solução utilizava um **Arduino Uno** conectado a uma **protoboard** e ao **sensor DHT11**.

O sensor DHT11 era responsável por realizar a leitura de informações do ambiente, principalmente:

* 🌡️ Temperatura
* 💧 Umidade

O Arduino recebia os dados coletados pelo sensor e servia como parte central do sistema de monitoramento.

Essas informações poderiam ser utilizadas para acompanhar as condições do ambiente e identificar situações que exigissem atenção no cultivo.

## 💻 Site

O projeto também conta com uma interface web desenvolvida para apresentar a proposta da HumiTech, seus produtos e a aplicação da tecnologia no agronegócio.

O site foi desenvolvido com foco em uma interface moderna e relacionada ao tema de **agricultura e tecnologia**.

## 🎯 Objetivo

O principal objetivo da HumiTech era demonstrar como conceitos de **IoT, sensores e programação** podem ser utilizados para criar soluções voltadas ao agronegócio.

O projeto também proporcionou experiência prática com desenvolvimento web, integração entre hardware e software e criação de uma solução tecnológica.

## 🎓 Projeto acadêmico

Projeto desenvolvido como parte das atividades acadêmicas do curso de **Análise e Desenvolvimento de Sistemas**.
